# My Projects – Lucrezia Bernini

Selected academic and hackathon projects from my BSc in Artificial Intelligence and my MSc at EPFL.

The projects cover Natural Language Processing, Machine Learning, Deep Learning, Retrieval-Augmented Generation (RAG),
computational neuroscience and customer analytics. Each folder is a standalone project with code, documentation and results.

---

## Projects

### Marketing & Customer Analytics
- **[Customer-Analytics](Customer-Analytics)**
  Three end-to-end projects from the course *AI for Communication and Marketing*, each ending with a marketing strategy
  built on the results:
  - **Customer Segmentation:** RFM with data-driven thresholds and K-Means personas to tailor message tone and channel.
  - **Churn Prediction:** Logistic Regression, Random Forest and XGBoost propensity models (lift ~5.9× at the top 10%) and a risk-tier retention campaign.
  - **CLTV Prediction:** BG/NBD + Gamma-Gamma vs XGBoost on the Olist e-commerce dataset (62k customers) and a win-back campaign.

### Natural Language Processing
- **[NLP-AIMedQA](NLP-AIMedQA)**
  Medical Question Answering project comparing fine-tuning and prompt-based approaches with transformer models
  (T5, SciFive, Flan-T5, Phi-3-mini), evaluated with ROUGE, BLEU and BERTScore.

### Machine Learning & Medical Data Science
- **[Migraine_Analysis](Migraine_Analysis)**
  Longitudinal study on 179 patients evaluating anti-CGRP antibody effectiveness. Used **MICE** and **LOCF** to handle
  attrition and **mixed-effects models** to identify responder phenotypes based on clinical history.

- **[ML-Spotify-Popularity](ML-Spotify-Popularity)**
  Supervised machine learning analysis of Spotify track popularity using audio features and classical ML pipelines.

### Computational Neuroscience
- **[BrainModeling](BrainModeling)**
  Implementation of a 10-node **Wilson-Cowan** "MiniBrain" framework to simulate Alzheimer's disease and frontotemporal
  dementia. Used phase-plane analysis to show that pathology shifts the network's operating points.

### Retrieval-Augmented Generation & AI Systems
- **[Hackathon-Lausanne](Hackathon-Lausanne)**
  Civic RAG chatbot retrieving information from official Canton of Vaud PDFs and web content, built with an open-source
  LLM (Apertus), a Streamlit interface, Docker deployment and optional text-to-speech output for accessibility.

- **[Hackathon-Innovaite](Hackathon-Innovaite)**
  AI assistant that simplifies navigation of university websites through RAG-based retrieval and automatic email
  generation. Implemented both as a Chrome extension and as a native website integration, to reduce help desk workload
  and improve user experience.

### Core AI & Optimization
- **[Fuzzy-Systems-Evolutionary-Computing](Fuzzy-Systems-Evolutionary-Computing)**
  Function approximation with fuzzy logic systems optimized by evolutionary algorithms, including Particle Swarm Optimization (PSO).

### Deep Learning
- **[Deep-Learning-Hotel-Reviews](Deep-Learning-Hotel-Reviews)**
  Multi-input, multi-head neural network for joint prediction of hotel review type and rating (multi-task learning).
